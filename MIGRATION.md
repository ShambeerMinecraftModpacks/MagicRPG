# Миграция существующего мира на MagicRPG 2.1.7

Перед обновлением полностью остановите игру и скопируйте папку мира за пределы инстанса.

## Эффекты зелий

Числовые ID перенесены:

- Wizardry: `31–32` → `200–201`.
- Forbidden Magic: `71` → `202`.
- Thaumic Tinkerer: `86–89` → `203–206`.
- Aura Cascade: `93–98` → `112–114` и `117–119`.
- Blood Magic: `100–116` → `213–229`.
- Blood Arsenal Bleeding: `121` → `230`.
- Witching Gadgets: Knockback Resistance `117` → `207`, Dissolve `118` → `208`, Cinder Coat `119` → `209`.

Лимит массива эффектов в Extended Potions снижен с `4096` до `256`. Все эффекты сборки остаются в допустимом диапазоне до `230`, а Electroblob's Wizardry 1.1.5 больше не пытается копировать массив из 4096 элементов в собственный массив на 256 элементов.

Сохранённые активные эффекты содержат числовой ID. До обновления желательно открыть копию мира на старой версии и очистить временные эффекты у всех игроков и важных сущностей. После обновления проверьте повторный вход каждого игрока.

## Зачарования и улучшения фокусов

- EvilCraft Breaking: `101` → `226`.
- EvilCraft Life Stealing: `102` → `227`.
- EvilCraft Unusing: `103` → `228`.
- Forbidden Magic Hellfire: `42` → `84`.
- Forbidden Magic Pandemonium: `43` → `85`.

Старые предметы с числовыми ID зачарований обязательно проверяйте только на копии мира. Клиент и сервер должны использовать одинаковые конфиги.

## Биом

EvilCraft Degraded перенесён с `105` на `108`; DivineRPG Vethea остаётся на `105`. В старых чанках ID уже записан. Если старый мир генерировал EvilCraft-биом под ID 105, после обновления эти чанки могут отображаться как Vethea. Автоматическая безопасная миграция без анализа конкретного мира невозможна.

## Генерация руд

Генерация меди и олова снова включена одновременно в Thermal Foundation, Forestry и Tinkers' Construct. Изменение действует только на новые чанки; уже созданные чанки автоматически не перегенерируются.

Сначала проверяйте копию мира. Если она загружается неправильно, вернитесь к резервной копии и не сохраняйте повреждённый мир повторно.
