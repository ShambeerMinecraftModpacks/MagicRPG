# Выделенный сервер MagicRPG 2.1.7

## Подготовка архива

Серверные шаблоны находятся отдельно от клиентской сборки в `server-pack/` и не входят в клиентский экспорт. Из корня репозитория запустите `server-pack/prepare-server.ps1`. Скрипт создаст `build/MagicRPG-2.1.7-server` и ZIP рядом с ним, объединив общий серверный состав с файлами из этой папки.

## Первый запуск

1. Распакуйте серверный ZIP в пустую папку.
2. Установите актуальную 64-битную Java 8.
3. Запустите `install-server.bat` на Windows или `./install-server.sh` на Linux. Скрипт скачает официальный установщик Forge `10.13.4.1614` и установит серверные библиотеки.
4. Откройте `eula.txt`, изучите EULA Mojang и измените `eula=false` на `eula=true`, только если согласны.
5. Оставьте `online-mode=true`. По умолчанию также включён whitelist.
6. Запустите `start.bat` или `./start.sh`.

На Linux перед первым запуском выполните `chmod +x install-server.sh start.sh`.

## Безопасность

- Сервер стартует с официальным `log4j2_17-111.xml` и параметром `-Dlog4j.configurationFile=log4j2_17-111.xml`.
- `online-mode=true` запрещает вход без проверки аккаунта.
- `white-list=true` закрывает новый сервер до добавления игроков.
- `spawn-protection=0` нужен ServerUtilities; права задаются в `serverutilities/server/ranks.txt`.
- Не переносите `players.txt`, `ops.json`, whitelist, мир или резервные копии из публичного архива.

## Проверка

После первого запуска проверьте отсутствие `ERROR` в логах, вход обычного игрока, переходы по измерениям, рецепты MineTweaker, конфликтовавшие эффекты и резервное копирование в течение 60–90 минут.
