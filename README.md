# MagicRPG 2.1.7

Хардкорная магическая сборка для Minecraft 1.7.10 с общей прогрессией Botania, EvilCraft, Blood Magic, Witchery, Thaumcraft и DivineRPG.

## Версии и требования

- Minecraft: `1.7.10`.
- Forge: `10.13.4.1614`.
- Java: актуальная поддерживаемая 64-битная Java 8.
- Память: `4096–6144 МБ`. Больше памяти без измерений обычно не требуется.

Рекомендуемые JVM-параметры клиента:

```text
-Xms4G -Xmx6G -XX:+UseG1GC -Dlog4j.configurationFile=log4j2_17-111.xml
```

Файл `log4j2_17-111.xml` взят из официальной инструкции Mojang для Minecraft 1.7–1.11.2. Сторонний лаунчер должен запускать игру из корня инстанса и не удалять этот параметр.

## Установка клиента

1. Импортируйте архив сборки в совместимый лаунчер.
2. Выберите актуальную 64-битную Java 8.
3. Выделите 4–6 ГБ RAM.
4. Проверьте наличие JVM-параметра Log4j из раздела выше.
5. Для существующего мира обязательно прочитайте `MIGRATION.md`.

## Важные особенности 2.1.7

- Устранены 28 коллизий ID эффектов и коллизия ID биома 105.
- Генерация меди и олова включена во всех трёх источниках: Thermal Foundation, Forestry и Tinkers' Construct.
- Electroblob's Wizardry закреплён на `1.1.5`; TX Loader загружает ресурсы BugTorch.
- Автоудаление ошибочных сущностей Forge отключено: ошибка останется видимой и не удалит ценную сущность молча.
- Сетевые NBT/packet-лимиты снижены до 32 МБ, лимиты chunk loaders ограничены.
- Персональные файлы, кэши, карты, скриншоты и серверные runtime-данные не распространяются.

`AUDIT.md` содержит исходный статический аудит. После изменения модов нужен повторный тест чистого клиента, новой карты и копии старого мира.
